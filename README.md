# Рация

Лёгкий голосовой чат для игр с друзьями. Один файл: и программа, и сервер.
Любой компьютер становится сервером одной кнопкой, остальные подключаются по адресу и паролю.
Протокол совместим с [Mumble](https://www.mumble.info/): управление по TLS/TCP, голос по UDP, кодек Opus —
к серверу «Рации» можно подключиться и официальным приложением Mumble (в том числе с телефона).

Главные цели: игра всегда в приоритете, минимальная задержка голоса, минимум ресурсов.

| | |
|---|---|
| Процессор в простое | около 0,1 % (1 % одного ядра) |
| Память | около 25 МБ; сервер внутри программы — ещё около 12 МБ |
| Сервер во время разговора | около 0,5 % одного ядра |
| Задержка голоса (программная часть) | медиана 16–17 мс |
| Трафик | около 69 кбит/с, пока человек говорит; в тишине — ноль |
| Размер | один файл ~14 МБ, без зависимостей |

Замеры сделаны на Ryzen 5 4600H, Windows 11.

## Возможности

- **Сервер на любом компьютере:** «Подключение и настройки» → «Сервер» → «Включить сервер», задать пароль.
  Программа сама покажет адреса, по которым к нему подключаться.
- Подключение по адресу, имени и паролю; автоподключение и автопереподключение.
- Список участников с индикатором «говорит», громкость каждого участника отдельно.
- Говорить по кнопке (глобальная клавиша, работает в игре) или по голосу.
- Кнопки «Микрофон» и «Звук», выбор устройств, индикатор пинга.
- Шумоподавление: выключено / лёгкое (шумовой порог) / сильное (RNNoise; по голосу срабатывает только на речь).
- Проверка своего голоса — в это время остальные вас не слышат.
- Проверка сети: VPN, прокси, Wi-Fi, ретранслятор, занятый канал, плохая связь с роутером,
  а для сервера — закрытый брандмауэр, порт, который может занять Windows, правила сети ZeroTier.
  Многое чинится кнопкой «Исправить».
- Журнал (`%LOCALAPPDATA%\Raciya\raciya.log`, у сервера — `%APPDATA%\Raciya\server\server.log`).
- По желанию: приоритет голосового трафика (QoS) и ограничение фоновых загрузок во время игры.
- Обновление в один клик: программа сама находит новую версию в этом репозитории.
- Сворачивание в трей.

Нет и не будет: оверлея в игре, записи, плагинов, телеметрии, фоновых автообновлений.

## Установка

1. Скачайте `Raciya-Setup.exe` со страницы [Releases](../../releases/latest) и запустите.
2. Вставьте адрес сервера или код приглашения (можно и позже, в программе) и нажмите «Установить».
   Права администратора не нужны. Только если в коде приглашения есть виртуальная сеть ZeroTier,
   Windows один раз спросит разрешение, чтобы её подключить.
3. В открывшейся программе введите своё имя и пароль сервера.

Подробная инструкция для друзей — в [FRIENDS.md](FRIENDS.md).

`Raciya-Setup.exe` — это сама программа: запущенная не из папки установки, она показывает экран
установки, копирует себя в `%LOCALAPPDATA%\Programs\Raciya` и дальше обновляется сама.
Удаление — через «Параметры → Приложения».

## Как сделать сервер

1. «Подключение и настройки» → кнопка «Сервер» → «Включить сервер», задайте пароль.
2. Windows один раз спросит разрешение администратора: программа откроет порт в брандмауэре и закрепит его
   за собой (иначе Hyper-V, WSL или Docker могут занять его после перезагрузки).
3. Справа появятся адреса для друзей: в локальной сети, а если подключена ZeroTier — код приглашения.
   Отправьте адрес (или код) и пароль друзьям.

Через интернет к серверу подключаются, если у его компьютера белый IP (с пробросом порта на роутере)
или через виртуальную сеть ZeroTier, если IP серый. Сервер работает, пока запущена «Рация»;
без окна его можно запустить так: `raciya.exe --server [--port 64738] [--password …]`.

## Как это устроено

```
client/
  src/
    main.rs       режимы запуска
    ui.rs         окно, трей, экран установки (Slint, программная отрисовка — без видеокарты)
    core.rs       состояние, автопереподключение, клавиша «говорить», сервер на этом компьютере
    net.rs        клиент протокола Mumble: TLS/TCP + UDP, запасной TCP-туннель
    server/       встроенный сервер: вход, участники, пересылка голоса, сертификат, защита
                  от подбора пароля, порты Windows, перенос настроек Mumble Server из версии 0.2
    framing.rs    кадры управляющего канала (общие для клиента и сервера)
    ocb2.rs       шифрование голосовых пакетов OCB2-AES128
    audio.rs      захват, Opus, микшер, шумоподавление
    jitter.rs     адаптивный джиттер-буфер
    diag.rs       проверка сети
    zt.rs         локальная служба ZeroTier (виртуальная сеть для серого IP)
    log.rs        журнал
    update.rs     обновления через GitHub Releases
    system.rs     установка и системные настройки
  scripts/system-setup.ps1   всё, что требует прав администратора (только по необходимости)
  ui/app.slint               интерфейс
tools/                       выпуск версии, замеры, откат старых системных настроек
```

- **Задержка.** Кадры по 10 мс; кодирование и отправка идут прямо в потоке захвата звука,
  декодирование — в потоке вывода. Джиттер-буфер держит минимальный запас и подстраивается сам.
  Запись в сеть — отдельным потоком: звук никогда не ждёт сеть.
- **Сервер.** Один канал, вход по имени и паролю сервера. Голос пересылается сразу в потоке приёма UDP;
  участнику, у которого UDP не проходит, — через TCP-туннель. Медленный участник не задерживает остальных.
- **Приоритеты.** Звуковые потоки работают в классе «Pro Audio», голос сервера — с высоким приоритетом,
  всё остальное — с пониженным.

## Сборка

Нужны Rust, MSVC Build Tools и CMake (для кодека Opus).

```powershell
cd client
cargo test
cargo build --release      # target\release\raciya.exe
```

Запуск без установки (для разработки): `raciya.exe --no-install` или файл `raciya.toml` рядом с программой.
Проверки без окна: `raciya.exe --server --port 64739 --password test` и
`raciya.exe --headless --server 127.0.0.1:64739 --user A --password test --tone --talk 2000:1000`.

## Выпуск новой версии

1. Поднять `version` в `client/Cargo.toml`, закоммитить.
2. Выполнить `tools\release.ps1` — он соберёт программу, создаст тег и выпуск на GitHub
   и приложит `Raciya-Setup.exe`. У всех участников в окне появится «Новое обновление!».
